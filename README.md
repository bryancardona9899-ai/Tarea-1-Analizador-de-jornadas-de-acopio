# Analizador de Jornadas de Acopio

Aplicación desarrollada en Node.js para procesar registros de una estación comunitaria de reciclaje y generar reportes analíticos confiables sin alterar los datos originales[cite: 1, 2].

## Requisitos Previos
* **Node.js** (versión 18 o superior).

## Ejecución
Para ejecutar la solución completa y visualizar los resultados en consola, utiliza el siguiente comando en la raíz del proyecto[cite: 3]:

```bash
node src/index.js
